Original
==========

Create a complex rust lang proc macro named make_crud.

The make_crud proc macro function call has 3 possible key/value attributes:
- Methods: This value is which method handlers will be created. Possible values are post, get, put, and/or delete. This field is optional and the default is all method handlers are created.
- State:   The struct used as the state in the handler functions. Example: State {messages: Vec<Message>}, then only the struct name is provided.
- Table:   The field in the state struct. Example: state.messages

The make_crud proc macro function also has field attributes:
- Skip: Provide the methods which skip this field. Possible values are post, get and/or put. Post and put are with incoming requests, and get is with outcoming responses.


Which takes this struct:
```rust
#[macro_crate::make_crud(methods = post; get; put; delete, state = State, table = state.messages)]
struct Message {
	#[skip(post, put)]
	id: Uuid,

	file_id: Uuid,
	text: String,

	#[skip(post, put)]
	created_at: u64,
	#[skip(post, put)]
	updated_at: u64,
	#[skip(post, put)]
	deleted_at: u64,
}
```

And creates these structs:
```rust
// Skips any field with #[skip(post)]
struct PostPayloadMessage {
	file_id: Uuid,
	text: String,
}
// Skips any field with #[skip(get)]
struct GetPayloadMessage {
	id: Uuid,
	file_id: Uuid,
	text: String,
	created_at: u64,
	updated_at: u64,
	deleted_at: u64,
}
// Skips any field with #[skip(put)]
struct PutPayloadMessage {
	id: Uuid,
	file_id: Option<Uuid>,
	text: Option<String>,
}
```

And creates these HTTP method handler functions:
```rust
impl Message {
	// Attaches the correct State and Json struct
	//
	// This is basically a Message:new() where PostPayloadMessage is
	// the fields which get set, then default values for the other fields.
	async fn handle_post(
		Extension(state): Extension<Arc<State>>,
		Json(payload): Json<PostPayloadMessage>,
	) -> impl IntoResponse { *Sends 201 or 400* }

	// Attaches the correct State and Json struct
	//
	// GetPayload includes the limit which should be returned
	// and offset of where to start returning.
	// GetPayloadMessage is returned which will be all or some of Message fields.
	async fn handle_get(
		Extension(state): Extension<Arc<State>>,
		Query(params): Query<GetPayload>,
	) -> impl IntoResponse { *Sends 200 GetPayloadMessage or 400* }

	// Attaches the correct State and Json struct
	//
	// PutPayloadMessage includes which fields of Message can be updated.
	// All fields are optional (except id, which is what were updating)
	// and it updates any which are Some().
	// If all are None then skip updating and return 200.
	async fn handle_put(
		Extension(state): Extension<Arc<State>>,
		Json(payload): Json<PutPayloadMessage>,
	) -> impl IntoResponse { *Sends 200 or 400* }

	// Attaches the correct State and Json struct
	//
	// Dont delete anything but only set deleted_at to current time using unix_now() fn.
	async fn handle_delete(
		Extension(state): Extension<Arc<State>>,
		Json(payload): Json<DeletePayload>
	) -> impl IntoResponse { *Sends 200 or 400* }
}
```

And places everything like this:
```rust
struct Message {}

struct PostPayloadMessage {}
struct GetPayloadMessage {}
struct PutPayloadMessage {}

impl Message {}
```

GetPayload and DeletePayload structs need to be defined in one placed for all make_crud proc macros to use.
